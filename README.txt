Evenos landing page
===================
index.html      The full page. HTML, CSS and JS are all in this one file, so just open it in a browser.
assets/robot.svg  The 3D-style robot mascot as a standalone SVG (the page also has it inlined).

Notes
- The only external resource is the Google Fonts stylesheet (Sora, Manrope, Nunito). With no internet the page falls back to system fonts.
- To host: upload index.html (and assets/) to any static host.
