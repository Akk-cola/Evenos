Evenos landing page
===================
index.html         The full page (HTML, CSS and JS in one file). Open it in a browser.
favicon.svg        Site icon, linked from index.html.
assets/robot.svg   The robot mascot as a standalone SVG (the page also has it inlined).
*.png (if present) PNG versions of the icon for older browsers / iOS.

Notes
- Only external resource: Google Fonts (Sora, Manrope, Nunito). Offline, the page falls back to system fonts.
- To host: upload this folder to any static host.
